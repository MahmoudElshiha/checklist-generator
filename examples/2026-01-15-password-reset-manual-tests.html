Password reset — manual checksاستعادة كلمة المرور — الفحوصات اليدوية

Customers who forgot their password can now reset it with a code sent by email or SMS. The code is valid for 15 minutes and works once; after five wrong codes the account waits 10 minutes. These checks run by hand on the test server.

How to use this page

  1. Do section 0 first. After that, sections can be run in any order and by different people.
  2. For each check, do the Steps, then compare what you see with You should see.
  3. Tick the box only when every line under "You should see" is true.
  4. The coloured label at the start of a step says where it happens: Server Database Admin panel Website Mobile app API client Mailbox Phone (SMS).

يمكن للعميل الذي نسي كلمة المرور إعادة تعيينها برمز يُرسل بالبريد أو برسالة نصية. الرمز صالح 15 دقيقة ولمرة واحدة، وبعد خمسة رموز خاطئة ينتظر الحساب 10 دقائق. تُنفَّذ هذه الفحوصات يدويًا على خادم الاختبار.

طريقة استخدام هذه الصفحة

  1. نفّذ القسم 0 أولًا. بعده يمكن تنفيذ الأقسام بأي ترتيب ومن أشخاص مختلفين.
  2. في كل فحص نفّذ الخطوات ثم قارن ما تراه بـالنتيجة المتوقعة.
  3. ضع العلامة فقط عندما يتحقق كل سطر في «النتيجة المتوقعة».
  4. الوسم الملوّن في بداية كل خطوة يبيّن أين تتم: الخادم قاعدة البيانات لوحة الإدارة الموقع تطبيق الجوال عميل API البريد الهاتف (رسالة نصية).
When a check fails: don't tick it. Note the time, the page URL, the record you were working on (an order number, an id), the language you were in, and take a screenshot. Send it with the check number (e.g. 2.3). Then go on with the next check.
عند فشل فحص: لا تضع العلامة. سجّل الوقت ورابط الصفحة والسجل الذي كنت تعمل عليه (رقم طلب أو معرّف) واللغة المستخدمة، والتقط لقطة شاشة. أرسلها مع رقم الفحص (مثل 2.3)، ثم انتقل إلى الفحص التالي.

0. Setup0. التجهيز

  1. Server Deploy the release branch and run the migrations.
  1. الخادم انشر فرع الإصدار وشغّل الترحيلات.
git pull && npm ci && npm run migrate && npm run build
  • Every command finishes without errors.
  • The table password_resets exists.
  • تنتهي كل الأوامر دون أخطاء.
  • الجدول password_resets موجود.
  1. Admin panel Create reset-email@example.test (email only) and a second account with the phone +15550100.
  1. لوحة الإدارة أنشئ reset-email@example.test (بريد فقط) وحسابًا ثانيًا برقم الهاتف +15550100.
  • Both accounts can sign in with their current password.
  • يمكن للحسابين تسجيل الدخول بكلمة المرور الحالية.

1. Reset by email1. الاستعادة بالبريد

  1. Website On the sign-in page choose Forgot password and enter reset-email@example.test.
  2. Mailbox Open the test mailbox.
  1. الموقع في صفحة الدخول اختر نسيت كلمة المرور وأدخل reset-email@example.test.
  2. البريد افتح صندوق البريد التجريبي.
  • The page says a code was sent, without saying whether the account exists.
  • One email arrives with a 6-digit code and "valid for 15 minutes".
  • تقول الصفحة إن رمزًا أُرسل، دون أن تذكر إن كان الحساب موجودًا.
  • تصل رسالة واحدة برمز من 6 أرقام وعبارة «صالح لمدة 15 دقيقة».
  1. Website Enter the code and a new password; sign in with it.
  2. Website Try the same code again.
  1. الموقع أدخل الرمز وكلمة مرور جديدة؛ ثم سجّل الدخول بها.
  2. الموقع جرّب الرمز نفسه مرة أخرى.
  • Sign-in works with the new password, not the old one.
  • The second use is refused: "This code has already been used."
  • يعمل الدخول بكلمة المرور الجديدة لا القديمة.
  • يُرفض الاستخدام الثاني: «تم استخدام هذا الرمز مسبقًا.»
  1. Website Ask for a new code.
  2. Database Age it by 16 minutes, then enter it on the website.
  1. الموقع اطلب رمزًا جديدًا.
  2. قاعدة البيانات اجعل عمره 16 دقيقة، ثم أدخله في الموقع.
UPDATE password_resets SET created_at = created_at - INTERVAL 16 MINUTE
WHERE email = 'reset-email@example.test';
  • Refused: "This code has expired. Ask for a new one."
  • مرفوض: «انتهت صلاحية هذا الرمز. اطلب رمزًا جديدًا.»

2. Reset by SMS and limits2. الاستعادة بالرسالة النصية والحدود

  1. Mobile app In the app choose Forgot password and enter +15550100.
  2. Phone (SMS) Read the test phone's messages.
  1. تطبيق الجوال في التطبيق اختر نسيت كلمة المرور وأدخل +15550100.
  2. الهاتف (رسالة نصية) اقرأ رسائل هاتف الاختبار.
  • One SMS with a 6-digit code; no email is sent.
  • رسالة نصية واحدة برمز من 6 أرقام؛ ولا يُرسل بريد.
  1. API client Send five wrong codes to POST /api/password/reset, then the right one.
  1. عميل API أرسل خمسة رموز خاطئة إلى POST /api/password/reset، ثم الرمز الصحيح.
curl -X POST https://{test-host}/api/password/reset \
  -H "Content-Type: application/json" \
  -d '{"phone": "+15550100", "code": "000000", "password": "New-pass-123"}'
  • The first five answer 422; the sixth, even with the right code, answers 429 with retry_after about 600.
  • الخمسة الأولى ترد 422؛ والسادس حتى بالرمز الصحيح يرد 429 مع retry_after نحو 600.
